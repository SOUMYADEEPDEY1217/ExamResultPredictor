## 🧠 Machine Learning Engine

The predictive model assesses non-linear interactions across academic habits, attendance discipline, and socio-educational backgrounds.

- 🌲 **Algorithm:** Random Forest Classifier (`n_estimators=100`, `random_state=42`)
- 🎯 **Test Accuracy:** **88.7%**
- 🏷️ **Output:** Binary classification (`Pass` / `Fail`) with probabilistic confidence scoring

`GET https://examresultpredictor.onrender.com/`

```json
{
  "message": "Exam Predictor API is running!"
}
```

---

### 🔮 2. Generate Prediction
`POST https://examresultpredictor.onrender.com/predict`
`Content-Type: application/json`

#### 📥 Request Body
```json
{
  "Gender": 1,
  "Study_Hours_per_Week": 28,
  "Attendance_Rate": 84.5,
  "Past_Exam_Scores": 78,
  "Parental_Education_Level": 0,
  "Internet_Access_at_Home": 1,
  "Extracurricular_Activities": 1,
  "Final_Exam_Score": 75
}
```

#### 📤 Response Body
```json
{
  "predicted_result": "1"
}
```
> *Output Interpretation:* `"1"` = **Pass** | `"0"` = **Fail**

## 💻 Local Setup & Development

### 1️⃣ Clone Repository
```bash
git clone https://github.com/SOUMYADEEPDEY1217/ExamResultPredictor.git
cd ExamResultPredictor
```

### 2️⃣ Start Backend API (FastAPI)
```bash
# Set up Python virtual environment
python -m venv venv
venv\Scripts\activate      # On Windows
# source venv/bin/activate # On macOS/Linux

# Install dependencies
pip install -r requirements.txt

# Run server with live reload
uvicorn main:app --reload --port 8000
```
> 📍 API will be accessible at `http://127.0.0.1:8000` (Docs at `http://127.0.0.1:8000/docs`)

### 3️⃣ Start Frontend Client (React)
```bash
cd frontend
npm install
npm run dev
```
> 📍 Web interface will launch at `http://localhost:5173`
